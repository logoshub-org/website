Make Your Own Modules

How to make a devotional or a commentary for PocketSword, where to get the tools, and how to put the result on your iPhone or iPad.

PocketSword reads standard SWORD modules, the same format used by The SWORD Project and programs such as Xiphos. A module you make works in any of them. Most people never need this page: the app's built-in downloader installs the ready-made modules from CrossWire and eBible.org.

What a module is

A module is two things:

  • a small settings file, mods.d/<name>.conf, that says what the module is; and
  • the data files, in a folder under modules/, made from your text by a SWORD tool.

The tools turn a plain text file in the IMP format into the data files. In an IMP file each entry starts with a line $$$ followed by its key, then the text of the entry, up to the next $$$ line.

Where to get the tools

The tools (imp2ld, imp2vs, osis2mod and others) come with the SWORD utilities from CrossWire. The CrossWire wiki page DevTools: Modules lists the current downloads and describes each tool.

  • Linux: install them from your distribution. On Debian and Ubuntu the package is libsword-utils.
  • Windows: download the utilities from CrossWire's file mirror, as the wiki page describes. They need the ICU data library (icudt DLL) in the same folder. The Xiphos project also provides a set of the tools.
  • Mac: build the SWORD library and utilities from the source on the CrossWire site. The wiki page has the current instructions.

Run any tool with no arguments to see its usage. The options can change between versions, so check what yours prints.

How to make a devotional

A daily devotional is a dictionary-type module whose keys are dates written MM.DD.

  1. Write the text file, mydevo.imp, one entry per day (all 366, including 02.29):

    $$$01.01
Text for 1 January.
$$$01.02
Text for 2 January.
$$$12.31
Text for 31 December.

    Use plain text. A line that ends in a space inside an entry should end with a backslash (\) so that words do not join.

  2. Build the module data with imp2ld:

    imp2ld mydevo.imp MyDevo 2

    The last argument chooses the storage format (4, 2 or z). CrossWire's notes say the tool does not always build correctly without it, so use 2. This makes a RawLD module: a .idx file and a .dat file named after the module.

  3. Put the two files in modules/lexdict/rawld/mydevo/.

  4. Write mods.d/mydevo.conf:

    [MyDevo]
DataPath=./modules/lexdict/rawld/mydevo/mydevo
ModDrv=RawLD
Encoding=UTF-8
SourceType=Plain
Category=Daily Devotional
Lang=en
Version=1.0
Description=My daily devotional
About=Who wrote it and where it comes from.
DistributionLicense=Copyrighted; permission to distribute granted by the author
TextSource=Where the text came from

    Category=Daily Devotional is what makes PocketSword list the module under Devotionals. DataPath names the data files without their extension. Use a licence line that is true for your text.

  5. Zip the mods.d and modules folders so that both are at the top of the zip (see "Upload it to your device" below).

How to make a commentary

A commentary is keyed by verse instead of by date. One entry can cover a range of verses.

  1. Write the text file, mycomm.imp. Keys name a verse, a chapter or a range:

    $$$Genesis 1:1-5
Notes on the first five verses.
$$$Genesis 1:6
Notes on verse six.
$$$Exodus 1
Notes on the whole chapter.

  2. Build the module data with imp2vs:

    imp2vs mycomm.imp

    The tool takes the file and, optionally, an output path. If your text is already in OSIS XML, CrossWire's page says to use osis2mod instead. Run each tool with no arguments to see its options.

  3. Put the data files under modules/comments/ in a folder named after the module, in the same way as for the devotional.

  4. Write mods.d/mycomm.conf. It has the same keys as the devotional's, with these differences:

    [MyComm]
DataPath=./modules/comments/rawcom/mycomm/
ModDrv=RawCom
Versification=KJV

    ModDrv must match the format of the files the tool wrote (RawCom, RawCom4, zCom or zCom4), and DataPath must match where you put them. Versification says which verse numbering your keys follow (KJV is the common English one). Leave out Category=Daily Devotional.

  5. Zip the mods.d and modules folders as for the devotional.

The devotional steps follow CrossWire's documentation for imp2ld. For commentaries, check the driver name and the data path your tool actually produced before you write the .conf. A wrong ModDrv or DataPath is the usual reason a module installs but does not show.

Upload it to your device

PocketSword has a Module Maintainer Mode for installing a module you made without publishing it. You send the zip from a web browser on a computer on the same Wi-Fi network as your iPhone or iPad.

  1. Make the zip. The folders must be at the top level, with no outer folder around them: 
    mymodule.zip
  mods.d/mydevo.conf
  modules/lexdict/rawld/mydevo/mydevo.idx
  modules/lexdict/rawld/mydevo/mydevo.dat
    This is the same layout as CrossWire's "raw zip" packages. On a Mac, select mods.d and modules together and compress them, rather than compressing a folder that holds them.
  2. In PocketSword, open Preferences and turn on Module Maintainer Mode.
  3. Go to the Downloads screen, open its sources menu and choose Module Maintainer Mode. iOS asks for permission to use the local network the first time. Allow it.
  4. The app shows one or two web addresses, such as http://192.168.1.20:52000. Open one in a browser on your computer. Both devices must be on the same network. A guest network or a VPN can block this.
  5. On the page that opens, choose your zip file and press Upload. The page says "Installed" when it is done. The module is installed on the device, and a search index is built there.
  6. Close the screen in the app. Find your module under its tab: Devotionals for a devotional, Commentary for a commentary.

The upload page only accepts .zip files, and it lists the modules already installed on the device. Turn Module Maintainer Mode off when you have finished. The web page works only while the screen in the app is open.

If it does not work

  • The page will not open: check both devices are on the same Wi-Fi network, and that Local Network access is allowed for PocketSword in iOS Settings.
  • The upload says "Installed" but the module is missing: check the .conf file name, that DataPath matches the folder, and that ModDrv matches the data format.
  • A devotional is not in the Devotionals list: check it has Category=Daily Devotional.
  • Still stuck: send us a message and attach the .conf file.

Modules you make from other people's texts must follow their licence. To publish a module for everyone, see CrossWire's guidance on submitting modules.
