# Logos Hub

Making God’s Word easier to find, read and share.

Logos Hub is an Australian non-profit helping people access the Bible in the languages they understand best. We build free, open tools that connect people to open-source Bible translations and study resources from The CrossWire Bible Society and eBible.org.

Website: [www.logoshub.org](https://www.logoshub.org)

This repository contains the source for the Logos Hub website, a static site built with plain HTML and CSS.
