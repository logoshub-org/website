# Logos Hub

A public, non-profit digital library for the collection, preservation, and open distribution of the Bible, open-source Bible translations, as well as related study resources in electronic format.

Website: [www.logoshub.org](https://www.logoshub.org)

This repository contains the source for the Logos Hub website, a static site built with plain HTML and CSS.
